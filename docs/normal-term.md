# Editor Canvas Terminology

Use this table when discussion language and implementation language differ. Prefer the industry term in code, docs, comments, and commit messages.

| Discussion term                                        | Preferred term                                           | Meaning in this editor                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------ | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Outer canvas                                           | Workspace or pasteboard                                  | The bounded editor surface around the artboard.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Inner canvas                                           | Artboard or frame                                        | The editable output area with a chosen aspect ratio and pixel size.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Canvas section                                         | Workspace section                                        | Top editor section containing the fixed/collapsible sidebar and PixiJS workspace.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Timeline section                                       | Timeline panel                                           | Resizable bottom editor panel reserved for timeline/playback UI.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Sidebar section                                        | Editor sidebar                                           | Fixed-width left editor panel with its own collapse animation; it is not resizable.                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Fit canvas                                             | Fit artboard to viewport                                 | Recenter and scale the artboard so it fits inside the available workspace.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Canvas zoom                                            | Viewport zoom                                            | The zoom scale applied to the workspace view.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Canvas position                                        | Viewport translation                                     | The `x` and `y` camera offset used to pan the workspace.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Zoom shake                                             | Bound-clamp jump or zoom jitter                          | A visible shift when pointer-centered zoom collides with pan bounds.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Square grid                                            | Pixel grid                                               | A high-zoom grid where each cell is one artboard pixel.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Outer grid                                             | Workspace grid                                           | A future grid drawn on the dark pasteboard outside the artboard.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Video on canvas                                        | Video node or media node                                 | A live `HTMLVideoElement` rendered as a PixiJS video sprite.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Hover bounds                                           | Hover outline                                            | Non-selecting bounds shown around the canvas node under the pointer — including the artboard itself when the pointer is over its empty area.                                                                                                                                                                                                                                                                                                                                                                                                  |
| Click the canvas / select the background               | Artboard selection                                       | Clicking the empty artboard (or its padding margin) sets `selectedItemId` to the `ARTBOARD_SELECTION_ID` sentinel, draws the selection outline around the artboard, and routes the sidebar to the Background tab. Clicking the pasteboard deselects.                                                                                                                                                                                                                                                                                          |
| Cover like DOM                                         | Object-fit cover crop                                    | Preserve media aspect ratio while the frame crops the visible source area.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Stretched video                                        | Aspect distortion                                        | Non-uniform scaling of the video pixels; avoid it for normal media frames.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Elastic artboard / rubber canvas                       | Canvas bitmap stretch                                    | Preview-only non-uniform scaling when the browser stretches old PixiJS pixels during workspace resize. Keep the renderer buffer and CSS canvas box in sync, then paint the resized Pixi scene immediately so stale artboard/content pixels are not presented in the new surface.                                                                                                                                                                                                                                                              |
| Auto layout / video position                           | Derived video placement                                  | `computeVideoPlacement` in `lib/video-placement.ts` — `x/y/width/height` recomputed from artboard size + padding for every canvas video (all roles); persisted for v1 compatibility, never gesture-edited; rotation always written as 0. Transform handles, selection toolbar, lock, duplicate, and keyboard nudge were removed with the transformer (2026-06-06).                                                                                                                                                                            |
| Ratio dropdown                                         | Artboard preset dropdown                                 | Footer menu for Wide, Vertical, Portrait, Standard, and Square presets.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Zoom percentage in timeline                            | Canvas zoom menu                                         | Footer menu and readout for fit, 50%, 100%, 200%, zoom in, and zoom out.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Background add video button                            | Media import action                                      | Local `video/*` file picker in the Background tab.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Player controls                                        | Timeline transport controls                              | Theme-colored skip, play/pause, and playback time controls in the top toolbar.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Timeline block                                         | Timeline clip                                            | Non-destructive clip range that references one canvas video.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Left labels in timeline                                | Track label rail                                         | Fixed row-name column beside timeline lanes; omitted while keeping a 30 px start inset.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Color on tracks                                        | Role-colored track background                            | Role-tinted lane background; currently omitted in favor of neutral lanes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Lines every second                                     | Timeline grid background                                 | Full-height time grid in the lane area; currently disabled for a cleaner editor UI.                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Grpd snap / grid snap                                  | Timeline grid snap                                       | Snap timeline clip move/resize operations to ruler subdivisions.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Auxiliary line snap                                    | Timeline guide-line snap                                 | Snap clip edges to other clip edges or the playhead, with temporary vertical guides. Picks the **nearest** candidate edge within the 8 px magnet threshold.                                                                                                                                                                                                                                                                                                                                                                                   |
| Gap between clips / clip won't touch                   | Clamp-to-neighbour (clamp-don't-reject)                  | A move/resize that would overlap a neighbour or cross the timeline bounds returns an adjusted span (`clampZoomMove` / `clampZoomResize`) so the clip slides flush against the obstacle and pins there, instead of the step being rejected and the clip freezing short of the edge.                                                                                                                                                                                                                                                            |
| Tiny invisible gap / not exactly flush                 | Edge weld                                                | Commit-time pass that sets an edge within `ZOOM_WELD_EPSILON_SECONDS` (1 ms) of a neighbour edge / `0` / `timelineDuration` exactly equal to it, erasing pixel↔time float residue so flush clips abut with a zero-second gap in `project.json`.                                                                                                                                                                                                                                                                                               |
| Space between touching clips                           | Clip chip gutter                                         | The visual-only horizontal inset between a clip's action box and its rendered chip (`px-px`, 1 px per side). Time-flush clips render as touching with a hairline seam; any larger visible space is a real time gap.                                                                                                                                                                                                                                                                                                                           |
| Very small clip / sliver clip                          | Sub-minimum (legacy) zoom clip                           | A Zoom-track clip shorter than the 0.5 s creation floor (`MIN_ZOOM_CLIP_SECONDS`), creatable only under the old 1/60 s floor. Kept on hydration down to `ZOOM_CLIP_DEGENERATE_SECONDS` (1/60 s), still blocks placement/clamping as an obstacle, moves with its real duration, and grows to the creation floor on first resize.                                                                                                                                                                                                               |
| Clip add snapping / add lands flush                    | Add-placement magnet                                     | `placeZoomSpan`'s `snapSeconds` (8 px at the current zoom): hover-ghost anchors snap flush to the previous clip's end or `0`; the ghost end extends flush to the next clip's start or the timeline end. Prevents sub-minimum, unfillable micro-gaps between clips.                                                                                                                                                                                                                                                                            |
| Tiny clip content / icon spills over                   | Chip content density ladder                              | Width-driven content tiers shared by the hover ghost and committed zoom chips: full (icon + label + scale) ≥ 76 px, icon-only ≥ 20 px, bare marker below. Stops fixed-size content from bleeding over a narrow chip and reading as overlap.                                                                                                                                                                                                                                                                                                   |
| Auto scroll                                            | Timeline edge auto-scroll                                | Scroll the visible timeline while dragging near the edge.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Ruler time style                                       | Ruler tick label format                                  | Clock-style ruler labels such as `0:15`; only compact major dots stay visible while labels keep a wide gap.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Timeline zoom                                          | Timeline zoom                                            | Increase or decrease timeline horizontal density.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Fit timeline                                           | Fit longest clip to width                                | Default view that scales the widest timeline clip block to the visible width.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Play cursor                                            | Playhead                                                 | Current committed timeline time used to sync canvas media.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Secondary seek                                         | Hover preview                                            | Paused-only ghost cursor previewing the active clip frame, cursor overlay, and manual Zoom camera under the pointer from anywhere over the timeline (ruler **or** tracks); never writes the committed playhead. Emitted from the timeline root, suppressed during cursor/clip drags, and resolved against the active timeline clip when a video has been split.                                                                                                                                                                               |
| Hover frame sequence                                   | Hover preview frame coalescing                           | Paused-only hover preview samples active clip frames without writing the committed playhead; media seeks are coalesced per element so decoder work follows the newest hovered time.                                                                                                                                                                                                                                                                                                                                                           |
| Preview seek                                           | Hover preview seek                                       | Uncommitted secondary seek from timeline hover; previews media, cursor overlay, and manual Zoom camera while leaving `timelineTime` unchanged.                                                                                                                                                                                                                                                                                                                                                                                                |
| Smooth hover frames / live hover video                 | Live video hover preview                                 | Paused-only hover preview driven by the registered `HTMLVideoElement` seek pipeline. The canvas redraw callback paints landed frames from the same live video element; there is no editor-side proxy decoder or texture cache.                                                                                                                                                                                                                                                                                                                |
| Flicker while hovering / blank hover frame             | Seek-time texture hold                                   | Pixi video sprites stay renderable after their first successful `VideoSource.update()` while the clip is timeline-visible. `HTMLVideoElement.readyState` gates new uploads only; it must not hide the last uploaded frame during rapid hover seeks.                                                                                                                                                                                                                                                                                           |
| Lagged preview frames                                  | Stale hover seek completion                              | A decoded hover-seek frame arriving after the pointer has moved again; the provider paints landed decoded frames before reissuing toward the latest hover target, so hover keeps showing valid motion instead of blanking until the pointer stops.                                                                                                                                                                                                                                                                                            |
| Frames going forth and back                            | Stale seek redraw                                        | An older completed media seek repainting the canvas after a newer committed playhead seek.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Cut video edge                                         | Source trim                                              | Non-destructive source in/out change from resizing a timeline clip.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Frozen clip frame                                      | Inactive clip visibility                                 | Hide a media node outside its active timeline clip range instead of holding a frame.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Total timeline length                                  | Timeline duration                                        | The playback duration, initially longest source asset and then furthest clip end.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Sync with canvas                                       | Playback sync                                            | Keep media element source times aligned with the committed timeline playhead and preview redraws.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Start playing when I open a project / autoplay once    | Autoplay on open                                         | Start timeline playback once, automatically, the first time a project is opened (open/refresh/switch). Armed by hydration (`autoplayPendingRef`), consumed by the first video element to finish loading; session-only and cancelled by any explicit play/pause. See [editor-canvas.md → Autoplay on open](editor-canvas.md).                                                                                                                                                                                                                  |
| Step-and-step scrub / jumpy preview                    | Committed seek coalescing                                | One in-flight committed (scrub/click/skip) seek per element that paints each landed frame and reissues toward the latest playhead, so the preview tracks the drag instead of lagging in chunks. Tracked in `committedSeekStateRef`.                                                                                                                                                                                                                                                                                                           |
| Step one frame / nudge the playhead                    | Frame step                                               | Move the playhead by exactly one source frame (`stepTimelineFrame`); bound to `,` / `.` and the inner transport chevrons, and snapped to the clip's frame grid.                                                                                                                                                                                                                                                                                                                                                                               |
| Zoom track / zoom lane                                 | Zoom track                                               | Dedicated bottom timeline lane for manual zoom segments. `CanvasZoomClip { id, start, end, enabled, focus, scale, radialBlur, transition, radialBlurSettings }` persists under `zoomClips` and drives the composition zoom camera in preview and export. New saves no longer write `radialBlurSettings`; legacy project files may still contain the older full `radialBlurSettings` object / `easePreset`, which load safely.                                                                                                                 |
| Zoom block / zoom region                               | Zoom clip                                                | One segment on the Zoom track marking a full normal → zoom → hold → normal camera effect. Move/resize/select/delete mirror video clips; overlaps are blocked (snap to neighbour).                                                                                                                                                                                                                                                                                                                                                             |
| Continuous zoom / no 1x between clips / chained zooms  | Continuous zoom (clip weld)                              | Two near-adjacent Zoom clips whose camera transitions directly from one settled zoom to the next (scale **and** focus, e.g. `2.5x→1.7x`) instead of dropping to `1x` between them. Computed in `sampleZoomCameraAtTime`; welds when the inter-clip gap is small relative to the clips' durations. Distinct from **Edge weld** (float-residue clip-edge snapping in `project.json`). |
| Cursor follow / cursor stays in zoom / camera chases pointer | Cursor follow (zoom dead-zone clamp)               | While zoomed, the camera keeps the recorded cursor inside the visible window. Stateless: the cursor roams an inner dead zone (`ZOOM_FOLLOW_DEAD_FRACTION`) freely; crossing it pans the focus to pin the cursor at the dead-zone edge. Computed in `sampleZoomCameraAtTime` from `sampleCursorArtboardFocus`; shared by preview, hover, and export. Distinct from full pan/follow-cam (a lagging camera), which is deferred. |
| Ghost zoom block / preview zoom                        | Zoom ghost                                               | Translucent dashed preview of the zoom clip a click would add. Its internal UI adapts to width: full `+ Add Zoom` when wide, icon-only for medium gaps, and a plain dashed marker for hairline gaps where a fixed-size icon would read as overlap. The hovered seek is the committed start, while the right edge can shrink before a neighbour to avoid overlap. Shown on zoom-lane hover even during playback, committed on click, and independent from the paused-only Hover preview. Driven imperatively (`ZoomGhost`), never React state. |
| Manual canvas zoom / screen-studio zoom                | Composition zoom camera                                  | Output effect that scales and offsets the artboard contents inside the artboard clip. Distinct from viewport zoom, which only changes the editor workspace view.                                                                                                                                                                                                                                                                                                                                                                              |
| Video goes out of canvas during zoom preview           | Radial zoom blur overlay overflow                        | Preview-only failure where the DOM radial-blur overlay canvas is laid out larger than the workspace because its high-DPI backing-store size leaks into CSS sizing. Export can remain correct because it renders into an artboard-sized composite.                                                                                                                                                                                                                                                                                             |
| Artboard moves but zoomed video stays                  | Stale radial zoom blur overlay                           | Legacy preview-only desync where the DOM radial-blur overlay remained at its previous screen crop while the workspace panned. PixiJS now uses the shared native zoom-blur path instead of a separate DOM overlay.                                                                                                                                                                                                                                                                                                                             |
| Zoom speed / transition speed / zoom duration          | Zoom transition duration                                 | **Duration** sets the persisted `transition.durationMs` value: how many milliseconds each zoom-in / zoom-out ramp takes when the clip is long enough. The apparent speed is derived from target scale plus duration, so `4x` over the same duration moves faster than `2x`. Legacy per-clip `speed`/`easeIn`/`easeOut`/`curve`/`easePreset` values are still parsed but no longer exposed.                                                                                                                                                    |
| Zoom target / point to focus                           | Zoom focus point                                         | Normalized artboard-space anchor `{ x, y }` stored on a Zoom clip. The point can sit on any artboard edge or corner and remains fixed in rendered artboard coordinates while the camera scales around it.                                                                                                                                                                                                                                                                                                                                     |
| Zoom crop box / focused area                           | Visible zoom window                                      | The normalized rectangle of the artboard that will remain visible at the clip's target scale. The Zoom panel derives this rectangle from the fixed zoom focus point and scale, so it stays inside the artboard while the focus point remains the zoom origin.                                                                                                                                                                                                                                                                                 |
| Automatic zoom / smart zoom / AI zoom                  | Auto-zoom                                                | A high-recall, staged generator (`lib/auto-zoom/`) that analyses captured cursor moves + clicks (once on first open, plus a manual Regenerate) and emits ordinary manual Zoom clips. It is NOT a separate camera — it only computes each clip's start/end (when), focus (where), and scale (how much, by confidence); the manual Zoom track renders, persists, and edits them. See `docs/auto-zoom-algorithm.md`.                                                                                                                                                       |
| Where a click lands / pointer rest                     | Settle point                                             | The position auto-zoom anchors a zoom on: a click's point, or a drag's release point — never a mid-flight cursor position. Mapped to a normalized artboard focus via the shared `displayPointToArtboard`.                                                                                                                                                                                                                                                                                                                                      |
| Clear center / clear core / center radius              | Baked inner radius                                       | Fixed `2%` Pixi `ZoomBlurFilter` inner radius around the zoom focus point. The old `radialBlurSettings.centerSize` field name remains for project compatibility, but it is no longer exposed or written by new saves.                                                                                                                                                                                                                                                                                                                         |
| Radial blur / zoom blur / motion blur                  | Radial zoom blur                                         | Custom WebGL postprocess blur using Pixi `ZoomBlurFilter`-style one-sided samples toward the fixed zoom focus point, with randomized sample phase, parabolic weights, and zoom-velocity-weighted strength. It appears only during ease-in and ease-out; hold frames remain sharp. This is not a Konva filter/cache path.                                                                                                                                                                                                                      |
| Clip frame rate / fps                                  | Source fps (measured)                                    | Per-clip source frame rate measured during playback via `requestVideoFrameCallback`; session-only (`videoFpsRef`), drives frame-step granularity, defaults to 60.                                                                                                                                                                                                                                                                                                                                                                             |
| Margin around the recording                            | Artboard padding                                         | Inset of every canvas video from each artboard edge, stored in artboard pixels for direct control.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Fit inside padded box                                  | Padded contain-fit                                       | Aspect-preserving fit of every canvas video inside the padded inner rect; reveals background on the sides.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Border radius / rounded corners                        | Corner radius                                            | The squircle corner radius applied to a video node, stored in artboard pixels.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Smooth corners / iOS corners                           | Corner smoothing (squircle)                              | Per-node 0–1 smoothing factor; 0 = circular arc, 0.6 = macOS look, 1 = fully continuous-curvature squircle.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Radius limit / corner overflow / max rounding          | Per-corner squircle budget                               | `min(width, height) / 2` of the box being traced — the maximum distance a corner curve (radius **plus** smoothing extension `p = (1 + smoothing)·radius`) may extend along each adjacent edge. `computeSquircleCornerParams` caps `p` at this budget with figma-squircle's `preserveSmoothing` redistribution, so the traced outline can never self-intersect.                                                                                                                                                                                |
| Round camera                                           | Camera squircle (max radius)                             | Default camera appearance: corner radius = ½·min(w,h), smoothing = 1. Renders identically to the prior elliptical sceneFunc but goes through the unified squircle pipeline.                                                                                                                                                                                                                                                                                                                                                                   |
| Outline / stroke / frame                               | Node border                                              | Per-node squircle-following stroke. Width 0 hides it; offset (signed) and alignment (inside/center/outside) control where it sits relative to the node edge.                                                                                                                                                                                                                                                                                                                                                                                  |
| Border thickness                                       | Border width                                             | Stroke width in artboard pixels. `0` disables the border for the whole render path.                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Border outline color                                   | Border color                                             | CSS color for the stroke; defaults to `#000000`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Stroke alignment / inside-outside stroke               | Border alignment                                         | Where the stroke sits relative to the (already-offset) centerline: `inside`, `center`, or `outside`. Matches Figma stroke alignment.                                                                                                                                                                                                                                                                                                                                                                                                          |
| Border gap                                             | Border offset                                            | Signed gap in artboard px between the node edge and the stroke centerline; positive pushes outward, negative pulls inward.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Drop shadow / box shadow                               | Node drop shadow (removed)                               | The per-node squircle-following drop shadow (color / X / Y / blur / spread) was removed entirely on 2026-06-06 — no UI, renderer, export, or persisted fields remain; legacy `project.json` shadow fields are ignored on load. (The artboard's white "paper" drop shadow — a DOM CSS box-shadow — is unrelated and still exists.) |
| Click-to-open panel                                    | Sidebar selection bridge                                 | Mounting that auto-routes any video selection (canvas or timeline) to the Video tab and opens the sidebar.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| File item / file in video tab                          | Video file card                                          | One `Squircle` row in the Video tab's list view, showing a video's file name + formatted file size. On-canvas cards show **Select** (selects the video); detached cards show **Add** (re-attaches it).                                                                                                                                                                                                                                                                                                                                        |
| Delete video / remove from canvas                      | Detach video (remove from canvas)                        | `deleteVideo(id)` — moves a video off the canvas/timeline into `detachedVideos` without removing it from the project or deleting its file. The opposite of a true delete.                                                                                                                                                                                                                                                                                                                                                                     |
| Add back / re-add video                                | Re-attach video                                          | `addVideoToCanvas(id)` — puts a detached video back on the canvas with a fresh full-length timeline clip; keeps its appearance, while placement is recomputed against the current artboard settings (derived placement).                                                                                                                                                                                                                                                                                                                      |
| Removed-but-kept video                                 | Detached video                                           | A project video with `onCanvas: false` — not on the canvas/timeline, no clip, but still listed in the Video tab and persisted in `project.json`.                                                                                                                                                                                                                                                                                                                                                                                              |
| Unknown size                                           | File size fallback                                       | The `"Unknown size"` label shown by `formatFileSize` when a video's `fileSize` is `0` or non-finite (genuinely unknown byte count).                                                                                                                                                                                                                                                                                                                                                                                                           |
| Project file / save file                               | Project state file                                       | `project.json` next to `recording.json`; the autosaved `ProjectStateV1` document that fully describes the editor arrangement.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Project folder                                         | Project folder                                           | `~/Documents/openscreen/<ISO-timestamp>/`; one self-contained folder per recording, holding `recording.json`, the `.mov` files, `project.json`, and `assets/`.                                                                                                                                                                                                                                                                                                                                                                                |
| New window with that project / project-specific window | Project-pinned editor window                             | An editor `BrowserWindow` whose URL carries `?projectPath=<folder>`. `ProjectProvider` loads that exact folder first, so refreshing the window returns to the project it is already showing instead of whichever project is globally newest or active.                                                                                                                                                                                                                                                                                        |
| Project window name / editor window title              | Editor window title                                      | Native/document title for a loaded project editor: `{project-name}-openscreen`, derived from `ProjectSummary.name`. This is what macOS Window menus, Dock window lists, and task switchers should show.                                                                                                                                                                                                                                                                                                                                       |
| Click app icon / Dock icon / taskbar relaunch          | App activation                                           | OS activation or second-instance launch that restores the last focused editor window when any editor exists. It must not open the recorder, reload project URLs, or hide editor windows; recorder access comes from explicit recorder commands.                                                                                                                                                                                                                                                                                               |
| Recorder from Dock / tray / top bar / application menu | Recorder command surface                                 | Native menu entry point (`New Recording`) from the application menu, macOS Dock menu, Windows system tray, or macOS menu-bar status item. It opens or focuses `Recorder - openscreen` while preserving editor windows; during active recording it focuses recording controls instead.                                                                                                                                                                                                                                                         |
| Dragged-in video / external file                       | Imported asset                                           | A user-supplied video file copied into `<project>/assets/videos/<id>/`. Recorded screen/camera tracks are NOT imported assets — they stay where the recorder put them.                                                                                                                                                                                                                                                                                                                                                                        |
| Background image preset                                | Wallpaper                                                | A stock background image shipped with the app and referenced by stable `WallpaperId`; not copied per project.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Auto-save / save-on-edit                               | Autosave                                                 | The 500 ms debounced write of the current editor state into `project.json`, with extra flushes on window blur and `beforeunload`.                                                                                                                                                                                                                                                                                                                                                                                                             |
| Step back / take back                                  | Undo                                                     | Restore the previous document snapshot from the in-memory `historyRef` (Cmd/Ctrl+Z). Restores `{ artboard, videos, timelineClips, zoomClips }`.                                                                                                                                                                                                                                                                                                                                                                                               |
| Redo / replay                                          | Redo                                                     | Re-apply the next snapshot after one or more undos (Cmd/Ctrl+Shift+Z).                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Undo step                                              | History snapshot                                         | One `{ artboard, videos, timelineClips, zoomClips }` `ProjectStateV1` entry held in the in-memory undo stack. Pushed by the autosave-aligned push site.                                                                                                                                                                                                                                                                                                                                                                                       |
| Action category                                        | Commit tag                                               | Action-category label (`appearance`, `add`, `delete`, `preset`, `background`, `padding`, `grain`, `clip-move`, `clip-resize`, `zoom-add`, `zoom-move`, `zoom-resize`, `zoom-settings`, `zoom-remove`) stamped by each action.                                                                                                                                                                                                                                                                                                                  |
| Bundle window                                          | Coalesce window                                          | The 2 s window during which same-tag pushes replace the top entry instead of appending.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Save as video / render out                             | Export                                                   | Encode the current `ProjectStateV1` snapshot into a single `.mp4` / `.webm` file under `~/Documents/openscreen/exports/`.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Export settings window                                 | Export window                                            | Separate vibrancy-panel `BrowserWindow` (`exportWin` in `electron/windowConfigs.ts`) hosting the settings form + progress UI for an export job.                                                                                                                                                                                                                                                                                                                                                                                               |
| Settings window / app settings / preferences           | Settings window                                          | The vibrancy-panel `BrowserWindow` at `app/recording-settings/page.tsx` (`recordingSettingsWin` in `electron/windowConfigs.ts`). Hosts the Recording quality settings **and** the Editor preferences section (Autoplay on open, Remember sidebar tab) since 2026-06-07. Opened from the recorder bar's settings menu via `recorder:openRecordingSettings`.
| Time on the output timeline                            | Composition time                                         | Output-timeline position `T_c` in seconds, in `[0, timelineDuration]`. Drives `frame = T_c × fps`.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Time inside a source clip                              | Source time                                              | Per-clip seek position `T_s = sourceIn + (T_c − clip.start)`, in seconds. Computed only for clips active at `T_c`.                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Frame-by-frame render loop                             | Export frame loop                                        | The sequential per-frame loop in `run-export.ts`: sample output effects by composition time, decode active clips, draw changed layers, composite, then `videoSource.add()`.                                                                                                                                                                                                                                                                                                                                                                   |
| Combined output canvas                                 | Export composite                                         | The single stable PixiJS application canvas rendered each frame; the only canvas Mediabunny's `CanvasSource` reads.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Export render surface                                  | Export stage                                             | The offscreen PixiJS `Application` built from a `ProjectStateV1` snapshot. ## PixiJS migration terms

The Konva → PixiJS v8 migration (see `editor-canvas.md` → "PixiJS canvas") keeps the canvas vocabulary above — artboard, workspace, viewport zoom/pan, composition zoom camera, video node, etc. all map to Pixi constructs. A few implementation terms are new:

| Discussion term            | Preferred term             | Meaning                                                                                                                                                                                                                                 |
| -------------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pixi canvas / new canvas   | PixiJS canvas              | The `components/editor/canvas/pixi/` implementation that replaced the Konva `<Stage>`.                                                                                                                                                  |
| WebGPU/WebGL switch        | Renderer backend preference | Persisted `localStorage` choice (`openscreen:rendererBackend`, default WebGPU) in the titlebar's Renderer dropdown (right side, before Preview/Export); applies to preview + export, remounts the Pixi canvas immediately, and the WebGPU environment gate still wins. |
| Canvas node / generic node | Canvas node (`CanvasNode`) | In-memory node model (`{id,type} & NodeTransform`) the Pixi scene + pure hit-test math use; a read-side derivation of the persisted `CanvasVideoItem`, never serialized.                                                                |
| Imperative controllers     | Canvas controllers         | `scene` / `viewport-controller` / `selection-controller` / `video-controller` / `cursor-controller` — React owns state, PixiJS lives here, bridged via `pixi-canvas.tsx`.                                                               |
| Draw only when needed      | On-demand rendering        | `requestRender()` schedules one frame; a continuous loop runs only during playback (`beginPlayback`/`endPlayback`).                                                                                                                     |
| Fake Konva node            | Duck-typed node handle     | The `visible()/listening()/getLayer().batchDraw()` stand-in the Pixi video controller registers so the provider transport drives visibility and redraws; `batchDraw()` asks Pixi to paint immediately and upload any ready video frame. |
| Preview frame cache        | Avoided for editor hover   | Editor hover preview does not keep a secondary frame cache; it coalesces live `HTMLVideoElement` seeks and repaints landed frames through the canvas node redraw callback.                                                              |
